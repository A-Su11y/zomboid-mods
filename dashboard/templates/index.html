What to do

Pull the latest patches into your game

Double-click Update Frozen Zomboid on your Desktop before launching Zomboid. It only touches the frozen install — your normal Steam Zomboid is untouched.

Don't have the updater installed yet? Ask barti for the setup paste.

Report a mod that's broken in-game

Tell barti directly, or open an issue. Describe what you were doing and what you expected.

Help patch a mod yourself

Open the zomboid-mods folder on your computer, start Claude Code there, and tell it what you want to fix. The folder has a CLAUDE.md that explains the whole workflow — Claude will read it automatically.
